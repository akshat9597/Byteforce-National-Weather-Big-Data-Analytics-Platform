````markdown
# 🌦️ BYTEFORCE

## National Weather Intelligence & Analytics Platform

> **Observe • Analyse • Verify • Respond**

BYTEFORCE is a full-stack weather intelligence and analytics platform designed to unify **real-time weather observations, forecasts, geospatial analytics, anomaly detection, citizen reports, event verification, and situational awareness** into a single operational workspace.

The platform is being developed around **Smart India Hackathon 2026 – SIH26069: National Weather Big Data Analytics Platform**.

BYTEFORCE is designed as a real deployable system rather than a static dashboard or simulated prototype.

---

# 🌍 Problem Statement

Weather information is often distributed across multiple systems, APIs, bulletins, observation networks, forecasts, maps, and local reports.

This creates several challenges:

- Fragmented weather information
- Difficult state/district-level analysis
- Multiple incompatible data formats
- Limited correlation between official and citizen observations
- Delayed identification of emerging weather events
- Lack of unified provenance and verification
- Difficulty converting weather data into actionable intelligence

BYTEFORCE addresses this by creating a unified weather intelligence layer over multiple data sources.

---

# 💡 Proposed Solution

BYTEFORCE provides a centralized platform that can:

- ingest real weather information
- normalize multiple data sources
- store historical observations
- visualize data geographically
- detect weather anomalies
- correlate multiple reports
- accept citizen observations
- identify duplicate reports
- calculate event confidence
- provide verification workflows
- generate analytical dashboards
- track data provenance
- monitor source health
- provide near real-time updates

The platform is designed to scale from local monitoring to state and national-level weather analytics.
````

# 🔐 Email OTP Authentication

BYTEFORCE uses passwordless email authentication.

Authentication flow:

```text
User enters email
        ↓
FastAPI generates secure OTP
        ↓
OTP hash stored
        ↓
Resend sends email
        ↓
User enters OTP
        ↓
OTP verification
        ↓
Secure JWT session
        ↓
BYTEFORCE Dashboard
```

Email delivery is handled using **Resend**.

Authentication uses:

* 6-digit OTP
* OTP expiration
* resend cooldown
* limited verification attempts
* secure HttpOnly cookies
* JWT authentication
* role-based authorization

```text
     ↓

```

# 🩺 Source Health Monitoring

The platform can track external-source health.

Example:

| Source          | Status         | Last Update     |
| --------------- | -------------- | --------------- |
| Open-Meteo      | HEALTHY        | Recent          |
| Citizen Reports | ACTIVE         | Real-time       |
| IMD             | NOT CONFIGURED | Awaiting Access |
| MOSDAC          | PLANNED        | —               |

Possible states:

```text
HEALTHY
DEGRADED
STALE
OFFLINE
```

BYTEFORCE does **not** generate fake weather values when an external data provider becomes unavailable.

The most recent valid observation can instead be marked as stale.

# 📊 Data Authenticity

BYTEFORCE distinguishes data according to its origin.

### Real External Weather Data

Obtained from configured legitimate weather APIs.

### Citizen Data

Submitted by actual BYTEFORCE users.

### BYTEFORCE Analytics

Generated independently by the platform using observations, statistical methods and event-processing logic.

### Official IMD Information

Displayed as official IMD information **only when retrieved through authorized IMD services**.

BYTEFORCE does not fabricate or relabel simulated data as real observations.
