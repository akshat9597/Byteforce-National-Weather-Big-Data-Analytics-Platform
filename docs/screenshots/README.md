Screenshots contain only guest/sample workspace data, with no personal login
credentials or production reports. They are actual UI captures, not mockups.
Some pages are scrolled to focus on the relevant panel. The small Next.js
indicator identifies the local development capture. These images do not establish
that the same version is currently deployed online.

Keep filenames stable when replacing captures: the root README uses relative
links so images render in GitHub and in a local checkout.
